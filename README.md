# GCB-Server

겜캐배 모드 기능을 다른 모드 단타에서도 이용할 수 있게 하는 모드입니다.

겜캐배 패킷 코드를 보고 자체제작한 코드들입니다.

## 사용법

```groovy
repositories {
    maven {
        url "https://repo.biryeong.kim/releases/"
    }
}

dependencies {
    modImplementation include("kim.biryeong:gcb-server:[VERSION]")
}
```

현재 버전은 `1.0.0+1.21.8` 입니다.
